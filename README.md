# uBot AI v2

Railway + Telethon + Gemini 3.1 Flash-Lite + SQLite.

Railway Variables wajib: API_ID, API_HASH, GEMINI_API_KEY, GEMINI_MODEL, SESSION_STRING, OWNER_IDS.

Commands: .onbot .offbot .aistatus .aireset .pai .allow .mute .unmute .ban .unban .menu

Di grup: set permission dengan `.allow allmember`, lalu setiap member yang ingin memakai AI menjalankan `.onbot` sekali. Setelah itu reply pesan AI, mention akun userbot, atau `.pai pertanyaan`.

SQLite dapat diarahkan ke Railway Volume dengan `DB_PATH=/data/ubot.sqlite3`.
